Affichée pour cette mission

Fiche à collecter

La fiche définit les champs et les statuts. Le chatbot en conserve une copie.

À quoi ça sert : si la mission est « Informer », cette étape est masquée. Si elle est « Collecter » ou « Hybride », cette fiche est disponible pour recueillir les informations du visiteur.

Les champs détaillés sont gérés dans la fiche de collecte, pas dans ce parcours de configuration du chatbot.
